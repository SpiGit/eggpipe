description: Создать новый ADR по шаблону
---

Создай новый ADR: $ARGUMENTS

Порядок работы:

1. Найди существующие ADR в `engineering/adr/` и определи следующий номер `NNNN`.
2. Имя файла: `engineering/adr/NNNN-<kebab-case-название>.md`.
3. Используй структуру:

   ```md
   # ADR-NNNN: <Название>

   - **Статус:** предложено
   - **Дата:** <YYYY-MM-DD>
   - **Связанные документы:** <ссылки на ТЗ и System Design>

   ## 1. Контекст

   ## 2. Решение

   ## 3. Последствия

   ## 4. Альтернативы
   ```

   Допускаются дополнительные нумерованные разделы (`Принципы`, `Алгоритм`, `Открытые вопросы`)
   по образцу ADR-0001.

4. Опирайся на актуальное ТЗ и System Design; не противоречь им. Если решение меняет требования —
   явно укажи, какая версия ТЗ должна быть обновлена.
5. Не изменяй существующие ADR.
6. Покажи новый файл и diff. Статус «принято» ставь только после подтверждения пользователем.
