- Тесты: 376 passed; coverage 85.54%.
- Документация версионируется через `mike`: `major.minor`, alias `latest`.

## Процессы

- `main` защищён; изменения только через PR и `ci-success`.
- Trunk-based: `feat/*`, `fix/*`, `docs/*`, `chore/*`; постоянной `develop` нет.
- Релизы — теги `vX.Y.Z` на `main`; теги `v*` защищены.
- Deprecation — ADR-0016; версионирование docs — `major.minor` + `latest`.
- PR создаётся через `uv run python tools/create_pr.py`.
- После зелёного CI PR ревьюит subagent `pr-reviewer` (Qwen3.8 Flash), максимум две итерации.
- Бюджет PR: до 500 hand-written строк и 15 файлов; больше — stacked PR.
- После первого ревью правятся только находки; minor — в `Backlog candidates`, не в backlog.
- `CHANGELOG.md`, `backlog.md`, `AGENTS.md`, `CONTRIBUTING.md`, `docs/ai/**` — один владелец.
- Rebase только при `behind`/`dirty`; `clean` PR мержится без rebase; `rerere`/`zdiff3` включены.
- Независимые задачи можно параллелить в отдельных worktree, если owned paths не пересекаются.
- Конец дня фиксируется по шаблону `engineering/day-closure.md` с Backlog closeout.
