- PR #79 закрыл B-047: `load()` трактует битый payload как промах
  (`ValidationError`/`ValueError`/`TypeError`/`ArithmeticError`/`RecursionError`);
  `__eggpipe_type__` в пользовательских словарях экранируется, `cache_version` = 2,
  `_closure_matches`/`_declared_inputs` используют мемоизированный `digest`.
  В `remember()` набор исключений уже — это и другие хвосты вынесены в B-051.
- Ревью: две итерации, обе `APPROVE`; находки итерации 2 → B-051.
- Тесты усилены: битые теги (`date`, `decimal`, не-строка, `mapping`, глубокая
  вложенность), `EGxxx` + путь через `CachedParser`, `--entity` → `len(calls) == 2`,
  тип `constraints.max`, мемоизация closure-хэша.
- Roadmap 0.5.0: пп. 1–2 закрыты; п. 3 (метрики, ТЗ v2.5, B-050) и п. 4 (бенчмарки)
