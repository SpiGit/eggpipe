# Сессия: Инициализация проекта metadata-generator

**Дата:** 2025-11-03  
**Сеанс:** Первая сессия проектирования

## Принятые решения

### Структура документа модели (header)
- `format` — тип формата (yaml, json, toml, python) — для future-proofing
- `version` — версия **схемы формата** (не версия модели!)
- `updated_at` — дата изменения в ISO 8601

### Входные данные
- Аудитория: **Fullstack / API-first** команды
- Генерация: **любой формат** (зависит от конкретного генератора)

### Уровни гибкости
1. Встроенные генераторы (14 штук)
2. Jinja2-шаблоны (полная кастомизация)
3. Плагинная система (свои генераторы через entry points)

### Стек
- Python
- Click или Typer (CLI)
- PyYAML (парсинг)
- Jinja2 (шаблонизация)
- pytest + hypothesis (тестирование)
