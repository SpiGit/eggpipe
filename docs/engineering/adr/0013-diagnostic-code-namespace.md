# ADR-0013: Пространство диагностических кодов Eggpipe

- **Статус:** принято
- **Дата:** 2026-11-13
- **Связанные документы:** [ТЗ v2.2 §9](../requirements/v2.2.md), [ADR-0011](./0011-public-api-v2-identity.md)

---

## 1. Контекст

Коды диагностик начинались с `MG` — от старого имени `metadata_generator`. Проект
переименован в Eggpipe, но коды остались в legacy-пространстве. Публичного релиза ещё
не было, поэтому смена префикса сейчас дешевле, чем после публикации.

## 2. Решение

- Префикс диагностик — **`EG`**: `EG000`, `EG007`, `EG033`, `EG301`.
- Номера сохраняются: `MGxxx` → `EGxxx`.
- Числовые диапазоны и смысл кодов не меняются.
- Коды стабильны и не переиспользуются.
- `MGxxx` остаются только в исторических ТЗ v1.0–v2.1, старых ADR/ревью и changelog.
- Актуальные код, тесты, user/AI docs и `docs/user/reference/diagnostics.md` используют `EG`.

## 3. Трассировка

| Было | Стало |
|------|-------|
| `MG000` | `EG000` |
| `MG007` | `EG007` |
| `MG033` | `EG033` |
| `MG034` | `EG034` |
| `MG301` | `EG301` |
| `MG302` | `EG302` |

Полная таблица — в `docs/user/reference/diagnostics.md` и ТЗ v2.2 §9.

## 4. Последствия

- `tools/check_docs.py` и `tools/build_ai_docs.py` используют regex/парсинг `EGxxx`.
- `docs/ai/diagnostics.json` пересобирается.
- Старые `MG` в истории не редактируются.
- При добавлении нового кода используется следующий свободный номер в соответствующем
  диапазоне.
