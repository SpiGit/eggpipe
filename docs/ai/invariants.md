# AI invariants

Жёсткие правила для агентов. При конфликте с просьбой пользователя — уточнить, а не нарушать
молча.

## Документация

- Актуальное ТЗ — только файл со статусом **Актуальная** в
  `docs/engineering/requirements/index.md` (сейчас `v2.2.md`).
- Исторические ТЗ (`v1.0`–`v2.0`) и старые ADR не редактировать.
- Новое поведение — новая версия ТЗ; ADR не переписываются задним числом.
- Термины: `ModelDocument`, `SourceModel`, `ModelSlice`, `Entity`, `FieldDef`, `EnumDef`,
  `UNSET`, `GeneratorPlugin`, `FormatPlugin`, `GenerationResult`.
- Документация — на русском; код, пути, флаги и идентификаторы — на английском.

## Код

- Ядро не содержит генераторов и шаблонов.
- Плагин не пишет файлы; только возвращает `Artifact`.
- `GenerationContext` и входы плагина не мутировать.
- Ошибки плагинов не должны ломать другие генераторы.
- Ownership — только глобальный `.eggpipe/manifest.json`.
- Не ослаблять path/symlink/casefold-проверки.
- Не логировать секреты; `config show` редактирует `*token*`, `*secret*`, `*password*`.

## Процесс

- Не коммитить, не push и не публиковать без явного разрешения.
- Не добавлять зависимости без согласования.
- Не удалять чужие незакоммиченные изменения.
- Перед завершением — полный набор проверок из `docs/ai/tasks.md`.
