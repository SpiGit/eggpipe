## Changelog

### v1.0-draft (2025-11-03)
- Начальная версия
- Определена структура документа модели:
  - `format` — тип модели (для парсера), **не привязан к генераторам**
  - `extends` — наследование типов
  - `version` — версия схемы формата
  - `updated_at` — дата изменения в ISO 8601
- Принцип «данные отделимы от генерации»: модель не знает что из неё генерируется
- Гибкий метакогфиг:
  - `sources` — определение источников данных (файлы моделей)
  - `input` в генераторе — выбор подмножества сущностей/enum'ов/типов
  - Один и тот же набор данных может идти в разные генераторы
- Описаны 14 встроенных генераторов
- Спроектирована плагинная архитектура
- Определён CLI-интерфейс
- Список открытых вопросов для уточнения
