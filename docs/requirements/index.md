## Changelog

### v1.0-draft (2025-11-03)
- Начальная версия
- Определена структура документа модели:
  - `format` — **тип модели** (domain), а не формат данных (sql-model, api-contract, python-dto, etc.)
  - `extends` — наследование типов (базовый тип → промежуточный → специфичный)
  - `version` — версия схемы формата
  - `updated_at` — дата изменения в ISO 8601
- Определены 6 встроенных типов моделей: base, sql-model, api-contract, python-dto, python-service, config, frontend-types
- Описаны 14 встроенных генераторов
- Спроектирована плагинная архитектура
- Определён CLI-интерфейс
- Список открытых вопросов для уточнения
