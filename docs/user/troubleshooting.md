# Troubleshooting

## Частые ошибки

| Код | Что значит | Что делать |
|-----|------------|------------|
| MG000 | YAML/файл не прочитан, duplicate keys, не-dict | проверить синтаксис и кодировку |
| MG002 | дубликат имени entity/enum/type | переименовать или убрать дубль |
| MG003 | дубликат поля | оставить одно поле |
| MG004 | неизвестный тип | добавить примитив/enum/type или формат-плагин |
| MG007 | `format` отсутствует/неизвестен | указать `format` или установить плагин формата |
| MG008 | версия не поддерживается | проверить `supported_versions`/`--version` |
| MG009 | `extends` не найден/цикл/глубина | проверить import-closure и цепочку |
| MG010 | `default: null` при `nullable: false` | сделать nullable или убрать default |
| MG018 | неизвестное имя в `input` | проверить `entities/enums/types` |
| MG022 | импорт/ресурс вне project root | использовать `--allow-outside-imports` осознанно |
| MG023 | YAML в `files` не является моделью | убрать из `files`, оформить как resource |
| MG025 | дубликат alias импорта | сделать alias уникальным |
| MG027 | пустой каталог модели | добавить слой или убрать каталог |
| MG029 | конфликт слоёв/format | проверить `extends`, формат и merge |
| MG031 | файл-слой содержит не одну сущность | оставить одну entity на файл |
| MG032 | дубликат alias ресурса | переименовать `as` |
| MG033 | генератор не поддерживает формат | расширить `input_formats` или сменить формат |
| MG034 | наследование/версии/схемы форматов | проверить `base_versions` и `schemas` |
| MG035 | дельта не добавляет ничего | убрать пустой слой |
| MG036 | glob без совпадений | проверить путь/шаблон |
| MG037 | `models.<dir>` для неизвестного каталога | исправить ключ |
| MG038 | путь одновременно в `files` и `resources` | оставить одно назначение |
| MG040 | некорректный artifact path/content | POSIX, без `..`, BOM, CRLF |
| MG041 | ownership-конфликт | `--force` только для unowned или `clean` |
| MG042 | дубликат/prefix/casefold путь | развести пути или locations |
| MG043 | `skip` для не-owned файла | файл не будет присвоен |
| MG050 | changed owned-файл не удалён | файл изменён вручную |
| MG051 | stale location в manifest | `eggpipe clean` |
| MG052 | manifest повреждён/версия | удалить/исправить manifest |
| MG300 | генератор/запись/drift | смотреть traceback и diagnostic |
| MG301 | нарушен контракт генератора | `input_formats`, сигнатура, return type |
| MG302 | неизвестный инжектируемый параметр | использовать только три типа |

## Частые ситуации

### «Неизвестный генератор»

Плагин не установлен или entry point не совпадает с `id`:

```bash
pip install -e ./my-plugin
eggpipe gen list
```

### «Файл не принадлежит генератору»

Файл создан вне Eggpipe или другим location. Сначала `eggpipe clean` или используйте
`--force`, если файл действительно не нужен.

### «Manifest уже используется»

Есть активный процесс или stale lock. Проверьте PID в `.eggpipe/lock`; если процесс не
запущен, удалите lock.

### `--check` возвращает 1

Артефакты отсутствуют или изменены. Посмотрите `--plan`, затем выполните `generate`.

### JSON содержит `stale_locations`

Изменился `output_dir` или генератор удалён из конфига. Выполните `eggpipe clean`.
