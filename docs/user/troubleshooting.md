# Troubleshooting

## Частые ошибки

| Код | Что значит | Что делать |
|-----|------------|------------|
| EG000 | YAML/файл не прочитан, duplicate keys, не-dict | проверить синтаксис и кодировку |
| EG002 | дубликат имени entity/enum/type | переименовать или убрать дубль |
| EG003 | дубликат поля | оставить одно поле |
| EG004 | неизвестный тип | добавить примитив/enum/type или формат-плагин |
| EG007 | `format` отсутствует/неизвестен | указать `format` или установить плагин формата |
| EG008 | версия не поддерживается | проверить `supported_versions`/`--version` |
| EG009 | `extends` не найден/цикл/глубина | проверить import-closure и цепочку |
| EG010 | `default: null` при `nullable: false` | сделать nullable или убрать default |
| EG018 | неизвестное имя в `input` | проверить `entities/enums/types` |
| EG022 | импорт/ресурс вне project root | использовать `--allow-outside-imports` осознанно |
| EG023 | YAML в `files` не является моделью | убрать из `files`, оформить как resource |
| EG025 | дубликат alias импорта | сделать alias уникальным |
| EG027 | пустой каталог модели | добавить слой или убрать каталог |
| EG029 | конфликт слоёв/format | проверить `extends`, формат и merge |
| EG031 | файл-слой содержит не одну сущность | оставить одну entity на файл |
| EG032 | дубликат alias ресурса | переименовать `as` |
| EG033 | генератор не поддерживает формат | расширить `input_formats` или сменить формат |
| EG034 | наследование/версии/схемы форматов | проверить `base_versions` и `schemas` |
| EG035 | дельта не добавляет ничего | убрать пустой слой |
| EG036 | glob без совпадений | проверить путь/шаблон |
| EG037 | `models.<dir>` для неизвестного каталога | исправить ключ |
| EG038 | путь одновременно в `files` и `resources` | оставить одно назначение |
| EG040 | некорректный artifact path/content | POSIX, без `..`, BOM, CRLF |
| EG041 | ownership-конфликт | `--force` только для unowned или `clean` |
| EG042 | дубликат/prefix/casefold путь | развести пути или locations |
| EG043 | `skip` для не-owned файла | файл не будет присвоен |
| EG050 | changed owned-файл не удалён | файл изменён вручную |
| EG051 | stale location в manifest | `eggpipe clean` |
| EG052 | manifest повреждён/версия | удалить/исправить manifest |
| EG300 | генератор/запись/drift | смотреть traceback и diagnostic |
| EG301 | нарушен контракт генератора | `input_formats`, сигнатура, return type |
| EG302 | неизвестный инжектируемый параметр | использовать только три типа |

## Частые ситуации

### «Неизвестный генератор»

Плагин не установлен или entry point не совпадает с `id`:

```bash
pip install -e ./my-plugin
eggpipe gen list
```

### «Файл не принадлежит генератору»

Файл создан вне Eggpipe или другим location. Сначала `eggpipe clean` или используйте
`--force`, если файл действительно не нужен.

### «Manifest уже используется»

Есть активный процесс или stale lock. Проверьте PID в `.eggpipe/lock`; если процесс не
запущен, удалите lock.

### `--check` возвращает 1

Артефакты отсутствуют или изменены. Посмотрите `--plan`, затем выполните `generate`.

### JSON содержит `stale_locations`

Изменился `output_dir` или генератор удалён из конфига. Выполните `eggpipe clean`.
