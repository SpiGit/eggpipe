# ADR-0006: Расширение формата документа

- **Статус:** принято (частично уточнено [ADR-0007](./0007-format-inheritance.md) и [ADR-0008](./0008-model-units-and-source-layouts.md))
- **Дата:** 2026-11-11
- **Связанные документы:** [ТЗ v1.2 §3.4, §6.3](../requirements/v1.2.md), [System Design §2.5](../system-design/index.md)

---

## 1. Контекст

Формат определяет схему YAML, набор примитивов и дополнительные поля. Если формат-плагин
заменяет базовую схему целиком, ломаются композиция, null-матрица и валидация. Нужен способ
расширять `entity-model`, не дублируя ядро.

## 2. Решение

- Встроенный `entity-model` зарезервирован; внешний плагин не может его переопределить.
- Формат-плагин, расширяющий `entity-model`, наследует `EntityModelFormat` и переопределяет
  hooks `parse_extensions` / `validate_extensions`, а также объявляет:
  - `format_names`;
  - `supported_versions`;
  - `primitive_types`.
- `parse`/`validate` базового формата не переопределяются: плагин расширяет поведение,
  а не заменяет его.
- Дополнительные поля складываются в `metadata[<format>]` у entity/field/enum/type/source,
  а не в произвольные ключи схемы.
- `format` и `version` обязательны; неизвестный формат — MG007, неизвестная версия — MG008.
- Один запуск — один формат; импортируемые документы обязаны иметь тот же формат и версию.
- Формат передаётся генератору через `GenerationContext.format` / `format_version`.
- Формат-плагин с полностью собственной схемой реализует `FormatPlugin` напрямую и принимает
  на себя всю валидацию.

## 3. Последствия

- Базовые правила композиции, null-семантики и диагностик сохраняются для расширенных форматов.
- Плагин не может молча добавить поле в базовую схему: только namespaced `metadata`.
- `primitive_types` формата используется валидатором; неизвестный тип → MG004.
- Публичный API `EntityModelFormat` и `FormatPlugin` должен быть зафиксирован в ТЗ v1.3.

## 4. Альтернативы

- Полностью независимый parser для каждого формата — отклонено: дублирование и расхождение
  семантики.
- Разрешить произвольные ключи в YAML — отклонено: `extra="forbid"` и предсказуемость схемы.
- Несколько форматов в одном запуске — отклонено в v1.
